# Token Launch Radar: pre-token protocols ranked

A make.fun token-radar-01 entry: a Node 22 (standard library only) program that builds a ranking dashboard of pre-token protocols from a snapshot of the 40 watched slugs, with a board.json of 200 rows, a deterministic build, and three dashboard screenshots in `screenshots/`.

Run it: `MAKEFUN_OUTPUT_DIR=out node main.ts`
